# OverManager Roadmap

What we're building, what's next, and how to tell us what you want.

> This is a living document — priorities shift based on what you ask for.
> Items here are intentions, not commitments, and dates are deliberately
> absent. Last updated: **July 2026**.

## Request a feature / vote

The roadmap is driven by miners, not by us guessing:

- **Request or upvote features** in
  [GitHub Discussions → Ideas](https://github.com/overbuildlabs/OverManager/discussions/categories/ideas)
  — one idea per thread; 👍 the existing thread instead of duplicating it.
  The most-upvoted ideas get pulled into **Next** first.
- **Report bugs** in [Issues](https://github.com/overbuildlabs/OverManager/issues).
- Not a GitHub person? Email
  [support@overbuildlabs.com](mailto:support@overbuildlabs.com) and we'll file
  it for you.

## Now — actively in progress

- **OverManager Cloud launch** — the web portal at
  [cloud.overbuildlabs.com](https://cloud.overbuildlabs.com): live farm
  monitoring from any browser, alerts, hashrate/uptime history, power & profit
  and hardware-health reports, multi-site farms, and remote miner actions.
  Free tier for live monitoring; paid plans for longer history and multi-site.
- **OverManager Mobile** — the companion app (alerts on your phone, farm
  monitoring on the go), heading toward public app-store release.

## Next

- **Code-signed Windows installers** — remove the SmartScreen "unknown
  publisher" warning.
- **More miner families** — driven directly by Ideas votes: tell us which
  hardware you run. (Recent additions came exactly this way: Bitaxe/NerdQaxe++,
  NerdMiner_v2, Antminer L7/L9.)
- **Pool reconfiguration for more brands** — remote pool changes currently
  ship for IceRiver; extending control support to more manufacturers.
- **Promo & referral codes** for Cloud plans.

## Later / exploring

- **Sign in with Google on the desktop app** (already available on the web
  portal).
- **Report exports** — CSV/PDF exports of the Cloud reports for
  accounting/clients.
- **Public API access** for Cloud accounts — build your own dashboards on
  your farm's data.
- **Team access** — multiple logins per Cloud account with roles.

## Recently shipped

- **v1.8.4** — OverManager Cloud integration, per-coin dashboards,
  auto-scaling hashrate units, Bitaxe/NerdQaxe++ + NerdMiner_v2 + Antminer
  L7/L9 support, Cloud Sync machine-identity hardening. See the
  [changelog](CHANGELOG.md).
- **v1.6.x** — per-device alert muting, notification diagnostics, keychain
  session persistence.
